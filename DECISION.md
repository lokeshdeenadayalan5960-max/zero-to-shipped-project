# Architectural & Design Decisions

## Project Goal
Build a mock design landing page for a **Resume Parser** (named *0 → Shipped Resume Parser*). 

## Core Requirements
- Users can upload a PDF to calculate a resume score.
- Display present and missing skills based on the uploaded resume.
- Client-side execution only (no backend server required).

## Tech Stack Decision
- **Framework:** React + Vite (migrated/chosen over vanilla HTML/CSS/JS for better component state management and modularity).

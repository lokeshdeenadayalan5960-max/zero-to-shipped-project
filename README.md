# 0 → Shipped Resume Parser (React)

Upload a PDF resume, get a score plus the skills it shows and the ones it's
missing. All parsing happens in the browser — no backend.

## Run it

```
npm install
npm run dev      # dev server at http://localhost:5173
npm run build    # production build into dist/
npm run preview  # serve the production build locally
```

The original plain HTML/CSS/JS version is kept in `vanilla/` for reference.
